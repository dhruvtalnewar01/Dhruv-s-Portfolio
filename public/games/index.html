// TERMINAL HACKING PROTOCOL

GOAL: Find the correct password hidden in memory before exhausting your 4 attempts.

1. LIKENESS SCORE:

  • When you pick a wrong word, the terminal displays >X/N correct.
  • This means X characters match the password in the exact same letter position.

2. SECRET BRACKET TRICK:

  • Scan memory for matching bracket pairs on the same line: (...), [...], {...}, or <...>.
  • Hovering them highlights the entire block. Click to either:
    • Dud Removed (erases a false password)
    • Tries Reset (restores your 4 attempts)

3. LOCKOUT:

  • 4 incorrect guesses will initiate permanent terminal lockout. Reboot to try again.
