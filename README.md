## 🧠 Architectural Philosophy

Modern digital portfolios represent static, linear artifacts in an era dominated by dynamic cognitive systems and spatial interactions. **Portfolio OS** refactors this paradigm from first principles:

1. **Deterministic Windowing Compositor:** A virtualized desktop kernel providing multi-window state coordination, drag-and-drop mechanics, z-index layering, and viewport adaptation without compromising 60 FPS rendering cycles.
2. **Autonomous Multimodal Voice Assistant (`Rose`):** An embedded voice intelligence interface integrated via WebRTC bi-directional audio streaming, facilitating zero-friction conversational interaction with natural turn-taking dynamics.
3. **Dual-Identity Spatial Reveal Pipeline:** An interactive hardware-accelerated radial clipping shader dynamically rendering contrasting structural identities through fluid mouse kinetics.
4. **Clinical & Perception Engineering Rigor:** Deep technical showcase of mission-critical AI systems spanning cardiovascular risk stratification engines and India-first autonomous road perception networks.

### 1. Window Management & Desktop Compositor
- **State Engine:** Powered by a lean, reactive **Zustand** store maintaining window geometries, minimized/maximized cascades, focused task orchestration, and active session histories.
- **Micro-Animations:** Pure mathematical spring physics orchestrating window transitions, window dock scaling, and context-aware glassmorphic navigation bars.
- **Traffic Light Controls:** Functional multi-state controls (Close, Minimize, Expand/Restore) with custom lifecycle hooks.

### 2. Autonomous Voice Agent (`Rose — Voice AI`)
- **Protocol:** Low-latency WebRTC full-duplex conversational audio pipeline utilizing the Vapi Client SDK.
- **Visual Synthesis:** Real-time state-reactive 3D visual orb animation with dynamic status badges (`Connected`, `Listening`, `Thinking`, `Speaking`).
- **Telemetry & Safety:** Completely decoupled client runtime token ingestion adhering to zero-trust secrets architecture.

### 3. Spatial Reveal & Dynamic Hardware Compositor
- **Bespoke Radial Masking:** Real-time dual-texture compositing computing cursor coordinates against screen-space aspect ratios, revealing the analytical alter-ego layer beneath the surface.
- **High-Performance Shaders:** WebGL particle fields and fluid physics shaders delivering high tactile visual feedback without GPU thermal throttling.

## 🔬 Flagship Engineering Portfolio

### 🫀 1. Clinical AI Decision-Support for Coronary Heart Disease
> *Early cardiovascular risk stratification combining structured predictive modeling, stateful multi-agent orchestration, and clinical vector retrieval.*

* **The Problem:** Conventional cardiovascular risk assessment remains siloed across heterogeneous clinical parameters, disparate risk tables (Framingham, SCORE2), and dense guidelines, resulting in cognitive overload and diagnostic delay.
* **The Solution:**
  * **End-to-End Orchestration:** High-concurrency **FastAPI** microservice coordinating tabular predictive models with LangGraph-based stateful agent workflows.
  * **Explainability & Grounding:** Integrated SHAP attribution calculations coupled with vector-retrieval (RAG) over peer-reviewed cardiothoracic literature to substantiate diagnostic recommendations.
  * **Reliability:** Strict schema enforcement via Pydantic with fallback mechanisms, auditable risk trace logs, and sub-second diagnostic generation.

---

### 🚗 2. ATMANIRBHAR AI — India-First Multimodal Road Safety Intelligence
> *Autonomous perception and collision-mitigation architecture purpose-built for high-entropy, unstructured traffic environments.*

* **The Problem:** Western ADAS stacks rely predominantly on structured lane markers, uniform vehicle profiles, and compliant pedestrian behaviour—assumptions rendered invalid by Indian traffic realities featuring mixed modalities (two-wheelers, auto-rickshaws, pedestrians, cattle) and non-standard roadways.
* **The Solution:**
  * **Heterogeneous Perception Pipeline:** Fine-tuned multi-scale YOLOv8/v11 vision backbones paired with monocular depth estimation and temporal motion tracking.
  * **Multimodal Edge Fusion:** Audio event localization (horns, sirens, brake screeches) integrated with spatial video streams for predictive collision alerts under zero-visibility or occluded circumstances.
  * **Edge Optimization:** TensorRT and ONNX quantized runtimes achieving >45 FPS inference speeds on constrained edge hardware.

## 🚀 Local Engineering Setup

### Prerequisites
- **Node.js**: `v20.x` or higher
- **Package Manager**: `npm` (`v10.x`+) or `pnpm`

### 1. Clone the Repository
```bash
git clone https://github.com/dhruvtalnewar01/Dhruv-s-Portfolio.git
cd Dhruv-s-Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy the template file to initialize your local development secrets:
```bash
cp .env.example .env
```
Populate `.env` with your secure keys:
```env
VITE_VAPI_PUBLIC_KEY=your_vapi_public_key_here
VITE_VAPI_ASSISTANT_ID=5366650e-13de-438a-8c8b-9e9c61daee69
```
> [!NOTE]
> The application includes graceful degradation; if keys are absent, the Voice AI will inform the user with intuitive telemetry rather than crashing the interface.

### 4. Launch Development Environment
```bash
npm run dev
```
Navigate to `http://localhost:5173/` in your browser.

## 🌐 Production Build & Continuous Deployment

### Automated Netlify CI/CD Pipeline (Recommended)
1. Fork or push this repository to your GitHub account (`dhruvtalnewar01/Dhruv-s-Portfolio`).
2. Log into the **[Netlify Dashboard](https://app.netlify.com/)** and select **Add new site > Import an existing project**.
3. Authorize GitHub and select `Dhruv-s-Portfolio`.
4. Netlify will automatically detect configuration from `netlify.toml`:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
5. Under **Site Configuration > Environment Variables**, define:
   - `VITE_VAPI_PUBLIC_KEY` = `<your-vapi-public-key>`
   - `VITE_VAPI_ASSISTANT_ID` = `5366650e-13de-438a-8c8b-9e9c61daee69`
6. Click **Deploy Site**. Every subsequent `git push` to `main` will automatically trigger an atomic, zero-downtime production deployment.

### Manual / Temporary Deployment Folder
A pre-compiled production build has been bundled into the `out/` directory:
- Can be dragged and dropped directly to [Netlify Drop](https://app.netlify.com/drop) for instantaneous staging.

## 🛡️ Security Protocol & Zero-Trust Architecture

- **Zero Secret Exposure:** All private keys and proprietary credentials are strictly excluded from source control via rigorous `.gitignore` rules.
- **Client Sanitization:** Only public-facing, scoped identifiers (`VITE_VAPI_PUBLIC_KEY`) are accessed within the client bundle.
- **HTTP Header Hardening:** `netlify.toml` delivers configured security headers (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`) to mitigate client-side injection vectors.
